The Observatory

Status that means something.

Every multiplexer shows you panes. zodiac reads them: it watches terminal titles, output rhythm, and screen contents to keep an honest verdict per agent — with a painted status rail, a finish chime if you want one, and desktop notifications when a pane rings its bell.

needs you

The agent stopped on a permission prompt or a question. zodiac parses the numbered options off the screen so every surface — TUI, phone, widget, notification — can offer real answer buttons.

working

Genuinely working — not merely printing. A stuck "working" pane with an unchanged screen for three minutes gets flagged, and an optional watchdog auto-resumes Claude Code API stalls.

finished

Done since you last looked. Finish states are sticky per pane, so nothing completes silently while you're focused elsewhere.

The Astrolabe

Your agents, from your pocket.

Pair a phone by pointing it at a QR code (Alt+P). From then on the native iOS app mirrors every pane live — full terminal scrollback, a keys pad, voice-dictation replies — and a push arrives the moment an agent needs an answer.

Home-screen and lock-screen widgets carry the question to you: tap an option without unlocking. Multiple computers, one sky. All of it rides a read-only observer mode in the server, so your attached session is never disturbed.

The Sanctum

Your model, or none at all.

An optional chat overlay (the oracle) answers questions about the session — or anything else — against an OpenAI-compatible endpoint you run: llama-server, Ollama, vLLM, on your own tailnet. A second small model can write one-line summaries under each pane and sanity-check stuck ones against your own written policy.

Both are off until configured. A fresh install of zodiac makes no background network calls, phones no vendor, and has no account to create. Pairing tokens live in your server's state dir and your phone's keychain — nowhere else.

The Ledger

Install it.

from source

git clone https://github.com/pr0vId3nce/zodiac cd zodiac cargo build --release

Rust stable. Linux is the primary target; macOS works.

nix

nix run github:pr0vId3nce/zodiac

A flake ships in the repo; add it to your system packages if it earns its keep.

releases

github.com/pr0vId3nce/zodiac/releases

Tagged builds for x86_64/aarch64 Linux and both macOS architectures.

The phone bridge installs with astrolabe/install.sh — it binds to your Tailscale address, so none of it ever leaves your tailnet.
